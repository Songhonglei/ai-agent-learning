# 课坊首屏亮点、图片与导航 · 2026-10-31

## 本轮四项交付

1. 首屏改“功能标签＋亮点标题＋具体说明”，三项可点击到对应内容：AI制课强调来源与人工审核；学习强调带引用的AI助教；运营强调灵活配额／预算提醒与自定义模型API。自定义API明确为支持协议内的主模型、备用与OCR接口，不声称已开放通用业务API或货币预算硬限。
2. 咨询与邮件入口和相邻链接统一使用text-link，字体、颜色、背景、边线与间距一致，无实底强调按钮。
3. 页面使用800／3200两档无损WebP与sizes/srcset，按屏幕和像素密度选择；PNG原图保持不变，只在点击后打开。首图优先，其余延迟加载。
4. 右侧六段竖条导航覆盖概览、制课、学习、运营、定制与联系；组中心位于视口61.8%高度，点击定位、滚动高亮、键盘焦点与减少动效均支持。窄屏收起文字标签，悬停／聚焦展示，细轨保持可用。

## 设计

延续纸色编辑式风格，墨绿亮点标题、陶土色章节号、宋体主标题与克制正文保持；首屏右列扩大，功能名作为小标签，亮点优先。DFII=(4+5+4+4)-3=14；主链是了解能力、浏览具体场景并邮件联系。导航融入外侧留白，不增加大型固定菜单。

## 图片验收

原PNG总计1,165,226字节；3200px无损WebP总计333,204字节，减少71.4%。逐张解码RGB像素与原图完全一致，同时保留原始Display P3 ICC色彩配置。800px版本先做高质量缩小再无损编码；不把低分辨率预览说成与原图逐像素相同。

在当前布局下，1440px／1倍像素密度预计选图总量248,636字节，比原四图减少78.7%；小屏1倍四图173,570字节，减少85.1%。这是资源字节比较，不是网络时间或真实用户性能分数。3200版首图86,634字节，原PNG330,801字节。原图链接与PNG字节保持。

初次比较发现1600px缩小后因抗锯齿颜色增加，反而比3200px无损WebP更大，故不发布该档，避免体积与质量两边吃亏。先比较编码结果，再决定响应式档位。
