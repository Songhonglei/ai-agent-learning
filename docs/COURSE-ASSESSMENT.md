# 全课程测评规则

实施日期：2026-10-21；范围：独立开源课程站。Cowork 未自动同步。

## 题卷与流程

- 固定题卷版本 course-2026-10-v1；前后卷各24道单选，每课2题，全部48个题干独立，不复用36道课内练习或1-1局部自测题干。
- 每题1分，总分24；来源限定于相应课审核来源。全部题目和答案随前端交付，属于学习自测而非防作弊考试。
- 前测可选，不阻断学习；后测要求12课均有完成记录。允许无前测后测，明确缺少基线；不能从1-1的局部分数推导全课程成绩。
- 逐题作答、题号导航、暂停续答、草稿及当前位置保存。提交前不显示正确选项、得分或解释；全部答完并二次确认后提交。首次提交结果保留，不提供刷分重考。
- 提交后逐题查看自己的答案、参考答案、解析和审核来源，并可返回课程复习。旧课内练习与单课自测行为保持。

## 对照口径

总分0–24，正确率=答对题数/24；对照同时展示分差与正确率百分点差（允许负值）。六个主题沿学习地图节点，逐课均为2分，后测未满分课程提供复习链接。

只有前、后测均已提交、同题卷版本、前测提交不晚于后测开始，且前测提交前无已记录学习行为时，才计算变化。前测作答期间产生的学习记录也使其成为补测；仍展示原始分数但不宣称提升。这里判断的是系统记录，不能证明用户此前从未学习。

两套卷覆盖同样目标，但难度尚未统计校准；无对照组和延迟复测，不把差值称作课程导致的效果或能力认证。建议10–15分钟只是作答预留建议，不是实测。

## 数据与兼容

schema v2 新增 courseAssessments，与旧 assessments 分开；v1读入后投影到v2并保留旧进度、错题、收藏及局部自测。每个测评记录包含种类、题卷版本、答案、当前题号、起始/更新时间、可选提交时间、是否已有学习记录；分数从当前版本题卷重新计算，不相信导入分数。

读取时校验题号、选项、版本和真实UTC时间；已提交记录必须24题完整。导入先预览再确认，优先较早的首次提交；两个草稿合并不同题的答案。跨标签修改保留其他题的新答案，已提交结果不会被旧草稿覆盖；提交时发生竞争修改则保留新草稿供再次检查。

云端沿用已有账号与JSON档案表。写请求按顺序执行，较早响应不回写覆盖新答案；保存中提示不要离开并注册浏览器离开提醒。服务器只接受v2写入、仍可读取旧记录，新前端负责迁移。真实Supabase未读写，本轮使用模型外的本地桩验证；不执行SQL迁移。

## 发布约束

必须同批部署前端和api/profile；仅更新静态前端会被旧API拒绝。发布后如需回退，应保留支持v2的读写保护和数据兼容，不能直接退回会丢弃测评字段的v1客户端与API；必要时先发兼容修复版。测试结果见 docs/testing/2026-10-21-course-assessment.md。
