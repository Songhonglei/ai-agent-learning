# 阶段2验收证据：课程引擎定型

> 验收日期：2026-08-11；验收结论：阶段2课程引擎定型通过，下一步进入阶段3内容批量生产。

## 1. 数据边界与迁移

- 全局学习档案使用 `ai-agent-learning:learning-profile` 与 `schemaVersion: 1`，为既定 12 课创建结构稳定的档案位；只有已编写的 1-1 会产生真实进度，其余 11 课保持空记录。
- 首次加载会读取阶段1旧键 `ai-agent-learning:lesson-1-1:progress`，把当前步骤、已完成步骤、实验选择、答案和主题投影进 1-1 档案。写入新档案并清理旧键全部成功后迁移才完成；重载不会重复改变已迁移档案。
- 存储和导入均按当前 Schema 投影字段。未知字段不会进入当前档案；结构损坏被拒绝；高于当前版本的档案明确提示“来自更新版本”，不会覆盖当前或旧版数据。
- localStorage 读取、写入、清理失败均有可继续学习和重试的恢复路径；跨标签只接纳最新且可验证的规范档案，并在并发动作前合并未冲突的数据变化。

Playwright 在 1440px 和 375px 两个完整场景中先写入带未知字段且步骤、完成项、实验选择、答案、主题均非空的阶段1旧键，再验证旧键已安全清理、新档案为 v1、1-1 状态保留、未知字段丢弃、其余 11 课没有假进度。随后测试在保留规范档案的同时原样回填同一份旧记录并重载，断言规范档案的原始 JSON 字符串逐字节不变，且旧键被再次清理；该验证不依赖会话播种守卫阻止旧键回填。

## 2. 备份、预览与固定合并

- 导出为本地 JSON，只包含版本、主题、当前课程、12 课进度位、错题、稳定收藏 ID、前后测结果和更新时间，不包含课程正文、解析、来源正文或模型内容。
- 导入先在本机完成 JSON、Schema 和版本校验，再展示逐课程取舍、收藏/错题去重结果及前后测规则；只有点击“确认导入”后才写入。
- 固定合并规则为：课程优先已完成步骤较多者，其次答案较多者，再比较有效更新时间；当前步骤按较新有效档案选择；收藏取并集去重；错题按课程与题目去重并保留较新记录；前后测分别保留较新有效结果。
- 端到端测试用内存测试文件分别走完“预览后取消”和另一份文件“预览后确认”。取消前后 localStorage 字符串完全一致；确认后新增收藏与现有来源收藏同时保留。测试没有读取外部文件或调用远程接口。

## 3. 1-1 全局学习记录

1440px 与 375px 均完成同一条真实链路：

1. 完成 3 题课前测，结果只作前后对照，不生成人群或能力标签。
2. 完成上下文构建器，选齐代码、流程和环境三类必要背景。
3. 在 3 道情境题中故意答错 1 题，验证答错不阻断学习且自动生成错题；同时收藏 `page-035` 来源卡。
4. 完成本课并完成 3 题等价但不复用题干的课后测。
5. 进入学习档案，验证前后测、错题与收藏汇总；在复习队列标记错题已掌握，未掌握计数归零且掌握状态写回全局档案。
6. 导出档案、检查投影字段与无课程正文边界，再分别完成取消导入和确认导入。

另有双标签场景：第一个标签收藏本课概念后，第二个标签的全局档案立即显示收藏及复习卡；第二个标签切换主题后，第一个标签同步主题，两个标签最终读取相同的规范档案。

## 4. 本地网络、视口与回归

- Playwright 对每个 HTTP(S) 请求严格断言 `origin === http://127.0.0.1:4173`；阶段2完整场景和阶段1回归不接受 `localhost` 别名、其他端口或其他来源。
- FAQ 展开期间单独统计 Fetch/XHR，请求数为 0；自由提问仍保持禁用，没有真实模型或教学网络依赖。
- 1440px 和 375px 均覆盖迁移、前测、实验、错题、收藏、完成课程、后测、复习掌握、导出及两次导入；完成后页面无横向溢出。
- 375/768/1024/1440 关键动作与无横向溢出回归、1440px 冻结容器尺寸、减弱动态效果及阶段1刷新恢复继续通过。
