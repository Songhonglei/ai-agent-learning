## 已冻结决定

1. 首期范围固定为5个Module、12课、6个学习地图节点；课程与互动归属以 `02-课程大纲.md` 为唯一口径。
2. 1-1固定使用“上下文构建器”，1-2固定使用“Prompt A/B对比”；阶段1先做1-1纵向样板。
3. 课程直接可进入，仅提示推荐顺序；前测、后测各3题，后测不复用题干。
4. 3-1纳入工具权限、人工确认和不可逆护栏；3-2纳入失败恢复与能力边界；4-2纳入多Agent有效的限定条件。
5. 视觉基线采用已冻结的Light/Dark Token、字体、布局和 `visuals/hongshu-avatar.svg`；移动端及加载、空、错误状态在阶段1实施并验收。
6. 技术采用React + Vite + TypeScript、CSS Variables + Tailwind、轻量状态容器、Storage Adapter、Vitest + Testing Library + Playwright；内容遵循冻结课程数据契约。
7. 阶段1只做本课进度恢复；全局Schema迁移与导入/导出由阶段2实现，同时覆盖恢复、损坏等边界。
8. 真实模型默认关闭；样板仅有自由提问入口占位和预置FAQ，不产生模型回答，不保存前端密钥，且不阻断预设课程。
9. html-go-live只是未来静态发布目标；没有发布或远程写入授权。
10. 来源完整性、断点恢复、题目人工审核和关键无障碍是硬门槛；行为与效果指标为观测目标。
