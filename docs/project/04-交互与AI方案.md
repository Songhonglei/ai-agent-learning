## 1. 单课交互流程

```
┌─────────────┐
│  情境导入    │  ← 红叔开场，引入场景
└──────┬──────┘
       ↓
┌─────────────┐
│ 对话式讲解  │  ← 预设对话脚本，分支可选
└──────┬──────┘
       ↓
┌─────────────┐
│  互动实验   │  ← 可操作的实验组件
└──────┬──────┘
       ↓
┌─────────────┐
│  情境测验   │  ← 选择题/判断题
└──────┬──────┘
       ↓
┌─────────────┐
│  自由提问   │  ← 自由提问入口占位与预置FAQ
└─────────────┘
```

## 3. 答案机制（三级反馈）

### 3.1 即时判断
- 答题后立即显示对错
- 答错不阻断课程，可继续
- 提供"我不知道"选项

### 3.2 深度解析
- 解释为什么对/错
- 关联本课核心知识点
- 提供反例说明

### 3.3 原书依据
- 引用原书页码和原文
- 提供延伸阅读链接
- 重要结论保留适用条件

## 4. AI方案：A+B组合

### 4.1 A：预设课程脚本（核心）

- **核心教学内容**采用预设分支
- **标准答案和解析**提前审核
- 保证准确性与稳定性
- **不依赖大模型**也能完成课程

### 4.2 B：课后自由提问（当前样板占位）

- 当前1-1样板仅提供 `free-question` 自由提问入口占位和预置FAQ；自由输入应引导至FAQ，不产生模型回答。
- 当前样板**不得调用线上模型、不得保存或暴露前端密钥**；预设课程、标准答案和解析不依赖模型。
- 自由问答**不能替代**标准答案系统。
- 实际模型回答、服务端保护、知识来源和调用预算均是未来单独授权事项；获批前不实施。

## 6. 导师"红叔"角色设定

### 6.1 角色定位
- **名字：** 红叔
- **身份：** 虚拟AI学习导师
- **性格：** 博学但不卖弄、成熟但不说教、直接但不生硬、幽默但不抢戏
- **形象：** 卡通形象，符合"博学AI大师"特征

### 6.2 表达方式
- 先说结论，再解释原因
- 先说人话，再补专业术语
- 类比之后说明类比边界
- 使用职场和生活场景类比技术
- 对常见误区进行善意调侃
- 答错时降低用户挫败感

### 6.3 禁止事项
- ❌ 嘲笑用户
- ❌ 居高临下地说教
- ❌ 为讲段子牺牲准确性
- ❌ 使用过于密集的网络热梗
- ❌ 冒充真人专家或原书作者
-  对不确定问题强行下结论
-  编造数据、案例或引用
-  在安全、隐私和不可逆风险提示中开玩笑

### 6.4 幽默规则
- 每课情境导入最多一次幽默
- 答错反馈最多一次幽默
- 核心知识讲解和标准答案中不插段子
- 段子结束后立即回到知识点

## 7. 前测与用户分层

### 7.1 v0.1方案
- **3题基线前测**（取消原5题分层测试）
- 不用于给用户贴标签
- 用于记录学习前认知水平
- 个性化分层推迟至v0.2

### 7.2 后测
- 完课后进行**3题后测**，展示学习前后变化
- 后测题目与前测等价，但**不直接复用题干**

---

## 8. v0.1学习路径规则

- 课程**允许直接进入**
- 当前置课程未完成时，仅提示推荐学习顺序，**不阻断学习**
- 学习地图用于展示推荐路径和课程归属，不作为进入课程的硬性门槛
