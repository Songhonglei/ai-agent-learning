> **执行策略：** 来源审计 → 基线冻结 → 纵向样板 → 引擎定型 → 内容扩展 → 联调发布。

## 0. 完整性口径

本项目不以逐字复制原书作为课程目标，而采用两层完整性：

1. **来源清点完整：100%。** `reference/原始文档.pdf` 中每一页、每个章节、编号图表和编号实验都必须登记去向。
2. **课程纳入完整：按目标用户选择。** 每项原书内容标记为“完整纳入、压缩表达、主动排除、疑似遗漏”之一；主动排除必须记录理由。

原始PDF是知识事实源，`reference/book-analysis.md` 是分析与选材层，12课及产品文档是课程表达层。产品、角色、视觉和技术选择不应伪装成原书结论。
