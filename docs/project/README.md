# 项目文档

本目录集中存放产品、课程与实施文档；它们是项目的可读规范，不参与前端构建。

1. `01-项目概述与PRD.md`：产品定位、目标用户与版本范围。
2. `02-课程大纲.md`：12 节课程、模块与互动设计。
3. `03-视觉设计规范.md`：视觉语言、主题和组件规范。
4. `04-交互与AI方案.md`：学习流程、互动机制与 AI 问答边界。
5. `05-技术架构建议.md`：技术选型、数据结构与部署建议。
6. `06-开发计划与验收标准.md`：阶段划分、验收标准与指标。
7. `07-决策与待确认清单.md`：已确认决策与待办事项。
8. `project_brief.md`：项目交接与背景摘要。

运行时课程依据仍在 [`../../reference/source-audit/`](../../reference/source-audit/)；请勿把真实密钥或原始受控材料放入本目录。
