# 云端学习档案保存与冲突处理

更新：2026-11-08。本轮是本地维护候选，尚未发布。

## 学员体验

正常保存沿用“正在保存学习档案”提示。其他窗口同时修改时，系统自动合并并显示“已合并其他窗口的学习进度并保存”。持续冲突或断网时保留当前页面的改动，提供重试与保存到本机。学员无需选择版本、比较版本号或处理技术字段。

退出、切换账号、切换本机存储或卸载页面会取消旧会话的读写；迟到的结果不再修改当前档案。相同账号的访问令牌刷新保留当前编辑，下一次保存使用新令牌。云档案尚在读取时不开放课程编辑，避免空档案覆盖已有进度。

## 内部并发协议

学习档案仍为 schema v2；JSON 备份和课程测评格式不变，不新增数据库字段或迁移。

- GET 验证当前用户，读取其 `profile,updated_at`，通过 ETag 返回内部校验标记。无档案时返回 null 与空档案标记。GET 不创建账号行、不更新元数据。
- PUT 必须携带最近读取到的 If-Match。缺少标记返回 428，提示刷新；旧 v1 写入继续被拒绝。
- 服务端核对标记，再使用 `user_id` 与 `updated_at` 的联合过滤执行原子 PATCH。首次保存使用插入且忽略重复键；返回零行时统一视为冲突。不能把“先读再无条件 upsert”当作并发保护。
- 每次成功保存的更新时间严格大于上一时间，避免同一毫秒或未来时钟导致标记重用。标记仅属于当前账号会话，不保存到学习档案或导出文件。
- 客户端发生 409/PROFILE_CONFLICT 后重新读取、合并并保存；最多三次写入、两次重读，整条保存链最多30秒。普通服务错误不自动重复写入。
- 服务端认证、数据请求与响应体读取共享15秒预算；客户端单个请求最多20秒。认证失效返回401，认证服务/数据服务异常及超时返回安全503。服务端只记录固定诊断码。

这些保证依赖所有档案写入方遵循本接口并更新 `updated_at`。直接绕过接口且不更新时间的数据库写入不在本轮并发保证内；RLS仍沿用现有账号所有权策略。

损坏或更新格式的本机备份不会被普通保存/重试覆盖；退出时即使本机备份不可读，也会清除页面中的旧账号资料。

## 合并规则

复用访客跨标签页的三方增量合并：以编辑开始前档案、当前编辑、最新云档案三者进行比较。

- 不同课程、不同题目或不同字段的编辑可以合并；收藏新增/移除和实验选择按本次改动应用。
- 同一字段双方都修改时保留已经保存到云端的选择，防止旧窗口覆盖它；合并结果会显示在当前页面。
- 已提交的全课程测评保留，不被草稿覆盖；提交过程中发现竞争草稿时保留草稿供学员检查，不静默提交。
- 保存响应到达时，将期间的新编辑继续叠加，避免旧响应覆盖新答案。
- 同页写入排队；失败后下一次保存/重试包含此前未保存的编辑。本机档案合并也进入同一队列。

## 本地验收

`npm run verify:core` 执行单元测试、服务端测试与构建。`npm run verify` 额外执行现有 Playwright E2E。可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已安装的 Chrome；CI使用ubuntu运行器预装Chrome，不下载浏览器。本轮交互验收直接使用ego-browser。

可运行合成账号服务（仅绑定127.0.0.1）：

```bash
npm run dev:sync-fixture
```

另一个终端启动带可选登录配置的前端：

```bash
VITE_SUPABASE_URL=http://127.0.0.1:3000 VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_fixture_only npm run dev -- --host 127.0.0.1 --port 5176
```

本地合成账号 `learner@example.com`、`other@example.com`，验证码 `123456`。不发送邮件、不使用真实账号。`/_test/control`可模拟服务错误及延迟，`/_test/state`仅返回该临时内存中的合成记录；它们只存在于验收脚本，不进入生产API。

此验收覆盖真实前端→实际档案API→内存PostgREST契约桩→界面，不证明真实Supabase部署、RLS策略或生产网络已通过。详见[本轮记录](testing/2026-11-08-cloud-sync-reliability.md)。

## 发布约束

本轮不部署、不推送触发预览，不改线上模型、Supabase配置或数据。未来需将前端和API同批发布，先验收真实账号/RLS及双设备保存。旧页面缺少If-Match会被新API要求刷新。回滚时必须保留条件写入及v2兼容；不能用无条件覆盖的旧接口作为并发保护回退方案。
