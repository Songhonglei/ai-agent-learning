# 开源项目验证经验

## 2026-10-21：将练习与结果测量分开

现有课内测验选择即反馈，适合练习；全课程前后测另设题卷、保存草稿、提交后反馈，并将既有学习记录标为补测。按课与主题覆盖测试、前后题干不复用检查、提交前无解析的浏览器检查已通过。不能仅靠前后分差证明课程因果效果。

## 2026-10-21：连续作答需要有序保存

原云端updateProfile可并发写完整档案，旧请求可能晚返回并覆盖新状态。修复为按顺序写入，仅在返回对应当前草稿时应用响应，期间提示等待。延迟保存桩测试确认第二笔排队、已选答案保持、最后完成后清除等待提示。本轮未用真实账号或数据库验证。

## 2026-10-21：对测评档案明确版本边界

v1读取投影为v2，旧局部成绩不冒充全课程基线；新版API拒绝v1写入防止降级覆盖。旧档案恢复和两种新测评草稿/结果JSON往返均有验证；发布前必须同时检查客户端与API的版本兼容。
