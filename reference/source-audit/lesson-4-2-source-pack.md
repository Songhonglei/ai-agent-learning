# 4-2《多个Agent怎么协作》来源包

本课只讲多 Agent 在“引入新信息、任务可拆分、需要并行或隔离”时的价值；多个 Agent 只是重复阅读同一段文字，通常不会在等量资源下天然更好。协作还需要清晰交接、共享空间规则和终止条件。
