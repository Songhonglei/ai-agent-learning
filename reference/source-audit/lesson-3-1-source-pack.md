# 3-1《Agent的工具箱》来源包

## 可讲结论与边界

课程用“感知、执行、协作”帮助非技术学习者理解工具分工，并以工具生态章节说明 MCP 的互操作角色。执行工具会改变外部世界，因此本课把权限、人工确认、取消/超时的不确定性和不可逆操作护栏作为硬边界。
