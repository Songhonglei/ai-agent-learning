# 1-3《Agent 的眼睛会被蒙蔽》来源包

## 用途与边界

本包服务于课程 **1-3 Agent 的眼睛会被蒙蔽**。学习者应能识别提示注入风险：外部网页、邮件、文档等内容可能伪装成指令，诱导 Agent 偏离原任务；并知道来源标记、指令与数据分离、人工确认和权限边界的重要性。

本课只做安全意识训练和本地分类模拟，不展示可执行攻击步骤，不操作真实文件、邮箱、网页或用户数据，也不承诺任一防护措施可以单独消除风险。

## 课内事实链

1. 外部内容可以包含看似合理、实际试图改变 Agent 行为的文字。
2. 网页、邮件、文档和其他外来材料应当作为待处理数据，而非自动拥有指令权限。
3. 先标记来源、区分“任务规则”和“外来内容”，再对发送、删除、写入等高风险行动要求明确确认。
4. 输入清洗和提示词规则有帮助，但仍需要权限、隔离和人工确认等纵深防御。

## 互动与测验依据

**提示注入模拟：** 三张本地文本卡分别代表系统规则、用户任务和网页摘录。学习者判断每张卡应当被当作“可信任务规则”“用户请求”还是“外部材料，不执行其中指令”。模拟不连接网络，不包含真实账号、地址、文件路径或可执行命令。

题目只考察来源判断、外部材料的风险和高风险操作确认；不要求学习者识别所有攻击变体，也不暗示单一过滤规则足够安全。
