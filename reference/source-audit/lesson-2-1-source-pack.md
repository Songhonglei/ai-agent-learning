# 2-1《AI为什么不知道昨天的新闻》来源包

## 可讲结论与边界

课程使用原书第 3 章的入门事实：模型已有知识未必包含最新进展；当问题依赖时效性或组织内部资料时，应取回受维护的资料再回答。知识库与用户记忆都会遇到过期和检索不准的问题。

| `outline-100-085` | PDF 100 / 印刷页 92 | 锚定知识库的时效与治理。 |
| `page-078` | PDF 78 / 印刷页 70 | 区分个体用户记忆与共享知识库，并提醒过期、检索不准。 |

互动仅为本地情境判断，不访问网络或真实企业资料；不承诺检索可保证答案正确，也不把所有问题都规定为必须检索。
