# 1-2《给 Agent 下命令的艺术》来源包

## 用途与边界

本包服务于课程 **1-2 给 Agent 下命令的艺术**。学习者应能识别系统提示词的作用，并在同一任务的两种写法中，选择目标、步骤与边界更清楚的流程驱动表达。

本课不教授 API、XML/Markdown 语法、缓存成本或模型训练细节；不把“流程驱动”表述为所有任务的唯一正确写法。

## 课内事实链

1. 系统提示词是 Agent 持续遵守的岗位说明书：身份、目标、权限和边界应在这里表达。
2. 单纯堆叠很多规则，会让优先级、当前步骤和例外处理变得难以辨认。
3. 对需要多步完成的任务，把目标、输入、步骤、异常处理和完成标准组织成流程，能让执行路径更清楚。
4. 好提示词不是越长越好；本课只主张让当前任务需要的约束清楚、可执行、可检查。

## 互动与测验依据

**Prompt A/B 对比：** 同一个“整理客户反馈”任务，一份为互相散落、重复且没有顺序的规则；另一份为目标、输入、步骤、异常和完成标准明确的 SOP。学习者选择更适合交给 Agent 执行的一份，并查看原因。

题目只考察系统提示词的持续作用、流程驱动的可执行性和规则堆砌的风险；不考察具体标签语法或保证成功率。
