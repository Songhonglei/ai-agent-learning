# 2-2《RAG：给AI装上“公司内网”》来源包

## 可讲结论与边界

课程将 RAG 转写为“先检索相关资料、再把资料与问题组织进上下文、最后生成回答”的入门过程。公司资料是知识来源，RAG 不是把所有文件塞进模型，也不替代资料维护与结果核对。
