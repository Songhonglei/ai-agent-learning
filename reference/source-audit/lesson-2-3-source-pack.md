# 2-3《Agent怎么记住“你是谁”》来源包

## 可讲结论与边界

课程区分当前会话线索、跨会话用户长期记忆和业务任务状态；同一用户信息可按不同粒度与结构保存，选择要在简单性、表达力、更新和检索之间权衡。新旧信息冲突时，记忆需要可审查地更新。
