## 2. 课程、节点与互动归属

| 节点 | 课程 | 核心互动（唯一归属） |
| --- | --- | --- |
| 认识 Agent | 0-1 你已经在用Agent了；0-2 三句话理解Agent | 0-1 识别身边的Agent应用；0-2 公式拆解 |
| 看懂上下文 | 1-1 Agent的记忆有边界；1-2 给Agent下命令的艺术；1-3 Agent的眼睛会被蒙蔽 | 1-1 上下文构建器；1-2 Prompt A/B对比；1-3 提示注入模拟 |
| 记忆与知识 | 2-1 AI为什么不知道昨天的新闻；2-2 RAG：给AI装上“公司内网”；2-3 Agent怎么记住“你是谁” | 2-1 有/无RAG回答对比；2-2 知识库检索模拟；2-3 记忆层次构建 |
| 工具与行动 | 3-1 Agent的工具箱；3-2 思考→行动→观察，再循环 | 3-1 工具链拼装；3-2 ReAct步骤播放器 |
| 评估 Agent | 4-1 怎么判断AI产品做得好不好 | 评估案例拆解 |
| 多 Agent | 4-2 多个Agent怎么协作 | 多Agent协作流程模拟 |

每课沿用“情境导入 → 对话讲解 → 互动实验 → 情境测验 → 自由提问”的流程；情境判断题覆盖全部课程。课程边界同时冻结：3-1纳入权限、人工确认和不可逆护栏；3-2纳入失败恢复和能力边界；4-2纳入多Agent真正有效的限定条件。详见 `docs/project/02-课程大纲.md`、`docs/project/04-交互与AI方案.md`。

## 3. 阶段1纵向样板

样板唯一范围为学习地图与 **1-1《Agent的记忆有边界》** 完整链路：预设课稿、上下文构建器、情境测验及三级解析、原书依据、localStorage断点恢复、Light/Dark主题、课后提问占位和FAQ降级、移动端关键流程、加载/空/错误状态，以及关键路径自动化测试。阶段1只做本课进度恢复；全局Schema迁移与导入/导出由阶段2实现。

阶段1必须以 `reference/source-audit/lesson-1-1-source-pack.md` 为来源输入：`figure-2-1` 是可重绘且有文字替代的语义核心图；`page-035`、`page-052` 规定可讲结论及边界。不得以样板开发改写该来源包或扩大12课范围。

## 4. 视觉与体验基线

- 直接采用 `docs/project/03-视觉设计规范.md` 的Light/Dark色彩Token、字体栈、1200px容器、首页学习地图布局、课程三栏布局和组件规格。
- `src/assets/brand/hongshu-avatar.svg` 是红叔头像基线；导师表达遵循 `docs/project/04-交互与AI方案.md` §6。
- 移动端页面与加载、空、错误状态须在阶段1完成实现与验收；它们不阻塞阶段1启动，但构成阶段1出口的一部分。
- 桌面端优先；移动端关键流程不得依赖拖拽。关键交互按 WCAG 2.1 AA 实现：键盘可达、焦点可见、对比度合格，且语义不能仅由颜色或图标表达。

## 5. 技术、存储与内容契约

- 技术栈：React + Vite + TypeScript；CSS Variables + Tailwind CSS；Framer Motion仅用于非阻塞反馈；轻量状态容器 + 统一Storage Adapter；Vitest + Testing Library + Playwright。
- 内容由课程JSON/TypeScript配置驱动；`Lesson`、`LessonStep` 的字段与步骤类型以 `docs/project/05-技术架构建议.md` §4 为契约，课程内容与组件分离。
- 阶段1的学习进度存储仅使用localStorage恢复1-1本课的当前步骤、完成状态、答案与实验状态，并处理本课恢复中的写入失败、损坏、多标签冲突和存储不足。全局 `schemaVersion`、Schema迁移、学习进度导入/导出、错题、收藏、前测与后测状态均由阶段2实现。
- 静态构建物未来可由 html-go-live 发布，但当前没有发布授权。

## 6. AI、发布与授权边界

| 边界 | 冻结结论 |
| --- | --- |
| 核心教学 | 预设脚本、标准答案和解析先审核；无模型时课程仍可完成 |
| 课后自由提问 | 当前样板仅有自由提问入口占位和预置FAQ；不能替代标准答案，也不产生模型回答 |
| 真实模型 | 默认关闭；样板不得接入线上模型或保存、暴露前端密钥 |
| 未来启用 | 实际模型回答仅能在单独授权后以服务端方式实施，并对输入长度、频率和超时设限；只使用审核知识；模型服务、服务保护、知识来源和预算须另行授权 |
| 发布 | 任何 html-go-live 发布或其他远程写入均须单独授权；本阶段未发布 |

## 7. 阶段1直接输入与验收

阶段1的直接输入为：本基线、`reference/source-audit/lesson-1-1-source-pack.md`、`docs/project/03-视觉设计规范.md` 的Token和 `docs/project/05-技术架构建议.md` 的数据契约。出口是新用户能从首页进入1-1、完成实验和测验、查看原书依据、刷新恢复进度并返回地图；移动端关键流程不依赖拖拽，加载、空和错误状态均有可理解且可恢复的呈现。来源完整性、断点恢复、题目人工审核和关键无障碍为硬门槛；使用行为和学习效果指标为观测目标。
